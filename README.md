# Mohamed Asmi Portfolio

Static GitHub Pages–ready portfolio website for Mohamed Asmi.

## Run locally

Open `index.html` directly, or serve the folder with any static server:

```bash
python -m http.server 4173
```

Then visit `http://localhost:4173`.

## Publish with GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the branch and `/root` folder.
4. Save and wait for GitHub to publish the site.

The hero portrait uses `assets/asmi.png`, the POSMate card uses `assets/posmate-dashboard.png`, links to `https://posmate.horixpro.com/`, and opens the companion mobile concept screens in `assets/posmate-mobile-concept.png`. The 360 Tour and ERPNext Education cards use clearly labeled imaginary concept images, and the ERPNext card links to `assets/education-mobile-concept.png`. Paper Partner includes real Google Play screenshot URLs, and the two role-specific CVs are included in `assets/`. Replace the placeholder GitHub URL and update any project links before launch. The contact form currently confirms locally in-browser; connect it to Formspree, Netlify Forms, Resend, or a Laravel endpoint when you add a backend.
